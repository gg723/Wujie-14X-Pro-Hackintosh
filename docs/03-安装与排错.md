# 03 · 安装与排错

## 一、安装前

1. **关掉 Secure Boot**（必须，否则 OpenCore 直接不启动）
2. 关闭第三方杀软对 ESP 分区的操作
3. 备份现有 ESP：至少把 `EFI` 目录整个复制一份到别处

## 二、生成本机 SMBIOS（必做）

仓库里的序列号 / MLB / UUID / ROM 都是占位值，直接使用没有 iCloud / iMessage。

1. 下载 [GenSMBIOS](https://github.com/corpnewt/GenSMBIOS)
2. 运行 → `1` 更新 MacSerial → `3` 生成
3. 机型填 `MacBookPro16,1`
4. 把输出写进 `config.plist → PlatformInfo → Generic`：
   - `SystemSerialNumber` ← `Serial`
   - `MLB` ← `Board Serial`
   - `SystemUUID` ← `SmUUID`
   - `ROM` ← 本机网卡 MAC 的 6 字节（Data 类型）

## 三、写入 ESP

把 `EFI/` 整个目录替换掉目标 ESP 的 `EFI/`：

```
ESP
└─ EFI
   ├─ BOOT\BOOTx64.efi
   └─ OC\
      ├─ ACPI\       6 个 .aml
      ├─ Kexts\      24 个 kext
      ├─ Drivers\
      ├─ Tools\
      ├─ config.plist
      └─ OpenCore.efi
```

Windows 上写 ESP 需要管理员权限，且不能直接挂载，一般用
`diskpart → select partition → assign letter=X` 后复制。

## 四、首次启动

1. 开机按 **F7**（不行试 F12 / Esc）选 OpenCore
2. 选 `macOS Installer` 或 `macOS` 进入
3. 首启会有几屏滚屏（因为 `boot-args` 带 `-v`），最后进桌面

进系统后建议立刻：

```bash
# 看 GPU 链路是否正常
tail -20 /var/log/phxboot.log 2>/dev/null

# 看内屏信息
ioreg -lw0 | grep -iE "PhxFBWidth|PhxFBHeight|PhxFBRefreshMilliHz"
```

## 五、排错：卡在 `Halting on critical error`

现象：

```
OC: ACPI patch (xxx) at N is borked
Halting on critical error
```

**含义**：第 N 条 ACPI 补丁的 `Find` 与 `Replace` **长度不等**，OpenCore 直接停机。

处理：

1. 断电重启，进 Windows
2. 打开 `config.plist`，检查 `ACPI → Patch` 里每一条：
   `len(Find) == len(Replace)`，且 `Replace` 不为空
3. 要么把补丁改成等长（只改方法名），要么 `Enabled = false` 先跳过
4. 同时把 `Misc → Boot → HaltLevel` 设为 `0`，以后不会因补丁问题停机

## 六、排错：黑屏 / 卡进度条

按顺序试：

| 现象 | 先试 |
|---|---|
| 卡 `[EB|#LOG:EXITBS:START]` | `Booter → Quirks → SetupVirtualMap` 开关互换 |
| 卡在 `apfs_module_start` | 补 `SSDT-EC`，或检查 `ResizeAppleGpuBars=-1` |
| 卡 `IOConsoleUsers: gIOScreenLockState 3` | 关掉 `-nohe` 试试；或等 GPU 组件装好 |
| 无限重启 | `boot-args` 加 `debug=0x100 keepsyms=1`，看最后一行 |

## 七、回退

### 回退 GPU 加速（回到软件渲染）

```bash
sudo touch /Users/Shared/gpu/phxboot-off
# 重启
```

### 回退 ACPI 补丁

把 `config.plist → ACPI → Patch` 里三条 TPD0 补丁的 `Enabled` 改成 `false`，
并把 `ACPI → Add` 里 `SSDT-TPD0.aml` 也改成 `false`。**两处必须一起改**，
只关补丁会留下「方法被改名但没有新定义」的中间态。

### 彻底回退

用你备份的原 `EFI` 目录覆盖回去。

## 八、装完顺手做的三件事

1. **自动登录**：系统设置 → 用户与群组 → 自动登录（不开的话重启后可能停在黑屏登录界面）
2. **关掉自动睡眠**：`sudo pmset -a sleep 0 disksleep 0`（睡眠未验证，先别让它睡）
3. **去掉 `-v`**：系统稳定后把 `boot-args` 里的 `-v keepsyms=1` 删掉，开机不再滚屏
